# Pulse Engine README artwork

`pulse-engine-banner.png` is the README hero banner. It was created on October 24, 2026 with the built-in image generation tool and reviewed at desktop and mobile README widths.

The banner follows the navy, teal, blue, and violet visual direction of [Plex Nano](https://github.com/keepithandy/plex-nano/blob/master/docs/assets/plex-nano-banner.svg) and [Stackquay](https://github.com/keepithandy/stackquay/blob/main/docs/assets/stackquay-banner.png), with an original Pulse Engine core and waveform emblem. It is decorative branding, not a screenshot of the engine or a claim about measured performance. The existing SVG was used as the starting reference.

The banner edges were repaired with a targeted image edit: black pixels outside the rounded navy artwork were blended into the matching background while preserving the composition.

The README also presents the project name and description as accessible text outside the image. Keep the banner proportional and allow it to shrink to the available width.
