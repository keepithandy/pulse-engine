# Pulse Engine README artwork

`pulse-engine-banner.png` is the README hero banner. It was created and updated on October 24, 2026 with the built-in image generation tool and reviewed at desktop and mobile README widths.

The banner follows the navy, teal, blue, and violet visual direction of [Plex Nano](https://github.com/keepithandy/plex-nano/blob/master/docs/assets/plex-nano-banner.svg) and [Stackquay](https://github.com/keepithandy/stackquay/blob/main/docs/assets/stackquay-banner.png). The selected logo depicts a seeded checkpoint branching into two timelines with explicit tick markers, reflecting repeatable simulations and forkable snapshots. It is decorative branding, not a screenshot of the engine or a claim about measured performance. `pulse-engine-banner.svg` is retained as the original waveform concept reference.

The banner has an opaque navy background, including the pixels outside its rounded outline, to avoid black corner margins.

The README also presents the project name and description as accessible text outside the image. Keep the banner proportional and allow it to shrink to the available width.

## Original banner generation prompt

Input images: Image 1 is the current Pulse Engine banner to redesign. Image 2 is the Stackquay banner, the primary style reference for richness, large typography, dimensional emblem and restrained luminous detail. Image 3 is the Plex Nano banner, a secondary reference for clean spacing, subtle navy grid, thin gradient top border and geometric connections.
Keep the Pulse Engine name, software simulation identity and pulse signal motif.
